This is the code that enables inseason.world. A platform to record and view localized produce season.

Produce seasonal data is often national, with little granularity and the data is too heterogenous to be considered reliable. This project aims at providing local, reliable and global produce seasonal data.

Farmers and gardeners can report seasonal data *at their location*. Customers can get reliable "what's in season now" list *at their location*.

## Setup

Rename .env.sample to .env, and change the values to something unique.

## Run the web server
Run the following:
make web
